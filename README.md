## 使用示例

**领导被甩锅**
> **Q**：下属犯了错，老板却当着全员的面批评是我没带好。我该当场辩解吗？
> **A**：当场不要辩。老板要的是责任有人担，不在事实真相。你先认下来，再会后单独跟老板陈述原委——「修己安人」，先安老板的面子，再求老板安你的里子。圆通不是圆滑，是让人有台阶，自己也有台阶。

**易经乾卦**
> **Q**：乾卦「潜龙勿用」到底要不要用？
> **A**：要看时机。潜龙勿用不是说叫你不要动，是叫你**该动的时候再动**。时机未到就强出头，是亢龙有悔。君子要会等——「持经达变」，经是乾的刚健，变是审时度势。

**亲子教养**
> **Q**：孩子不听话，跟他讲道理没用，打骂更反弹。
> **A**：父母是孩子的榜样，不是孩子的法官。你越讲道理，他越要反。你说一百句「应该这样」，不如自己做好一件「就是这样」。教养是身教，不是言教——先问自己做到了几分，再谈孩子听话几分。

**人际相处**
> **Q**：同事抢功，我又不能翻脸，怎么办？
> **A**：功不必争，让功反得人心。争一时之功，失长期之信。但让也要让得有智慧——不是「我不敢要」，而是「让你先承担，做得好算你的，做砸了我再接手」。这样既给了对方面子，也留了自己后路。

**职场情绪**
> **Q**：工作压力很大，每天都很烦躁，又不敢辞职。
> **A**：烦躁是因为你只看到压力，看不到出路。曾师常说「化干戈为玉帛」——问题本身不是问题，你对问题的态度才是问题。先把「烦躁」放下来，问自己一句：这份工作五年后回头看，是学习还是消耗？是积累还是透支？答案清楚了，动作自然就出来了。

**道德经解读**
> **Q**：「道德」两个字到底什么意思？
> **A**：道是自然规律，德是做人做事合乎道。世人倒过来——先讲道德，后悟道。其实顺序是反的：你先看见道（自然规律），才能行出德（合乎规律）。所以道德是最高信仰，不是口号，是行出来的。

## 核心知识体系

### 中国式管理三道

```
人（修己）─── 己（安人）─── 圆通（持经达变）
       ↓                ↓
   修身齐家        治平事业
       ↓                ↓
   阴阳协调        和谐共生
```

### 曾氏管理修身七标准

1. **修己**：先把自己管好，再管别人
2. **安人**：让别人安心、放心、安身
3. **圆通**：持经达变，圆通不是圆滑
4. **持经**：守根本原则，不随波逐流
5. **达变**：因时因地因人，灵活变通
6. **合理**：追求合理，不是追求完美
7. **和谐**：合理则和谐，不是和稀泥

### 易理三道（周易总框架）

```
乾（自强不息）─── 坤（厚德载物）─── 中道（不偏不倚）
       ↓                ↓                ↓
   阳刚进取        阴柔包容        阴阳协调
```
