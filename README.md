# zeng-shiqiang · 曾仕强思维蒸馏

> 把曾仕强（1934–2018，中国式管理之父，融汇儒道易理于管理与处世）的思维方式，蒸馏成可被 AI 调用的「曾师视角」persona 技能。

## 这是什么

一个人物思维 persona，不是中医/命理/金融技能。它让 AI 以曾仕强的口吻与思维框架，回应**管理领导、人际相处、情绪化解、人性洞察、易经/道德经义理、家庭教育**类问题。

- 触发词：`曾仕强视角` / `曾师会怎么看` / `中国式管理思维` / `圆通不是圆滑` / `持经达变` / `修己安人` 等。
- 不适用：中医诊疗、命理占卜、金融投资建议、纯西方管理学实证。

## 蒸馏来源（一手著作）

《中国式管理全集（23 册）》《领导的方与圆》《曹操的启示》《人际的奥秘》《人性的奥秘》《情绪的奥秘》《顺道者胜：讲道德经》《明理》《易经的智慧 1/2》——共 10 本（用户提供 txt）。
