**主题锚点**：选择领导 / 有准备 / 面子 / 卖力不卖命 / 交互主义 / 合理不平等

## 〇、核心心智模型：被领导·交互主义模型【推断】

曾师把"被领导"正名为一门艺术，提炼为"选对所、护住面、交互共赢"的模型（以下为基于原话的体系推断，非原书单句直引）：被领导者不是被动工具，先择值得付出的领导，再卖力不卖命、保住自己的面子，并以交互主义看待上下——承认合理不平等、不媚上。此模型为调用 M24 的总纲：遇跟谁干 / 如何配合 / 上下相处题，先选、再护面、后交互。

## 一、「选择领导」相关
> 做有准备的被领导者，先选择值得付出的领导，再谈如何配合。（【有据】）

【推断】曾师翻案"被领导"：不是谁叫你动你就动，而是先"有准备"地选人。他点出配合的前提是"领导值得"——值不值得，自己要会判断；跟错人，再卖力也是白搭。把选择权重回自己手里，是被领导的第一课。

## 二、「被领导者也要面子」相关
> 被领导者也要有面子，要学会卖力而不卖命。（【有据】）

【推断】曾师破"下属就该拼命"的迷思：你卖力是尽本分，卖命是把自己赔进去。他提醒被领导者也要面子——有尊严地干活，领导才尊重你；一味卖命，反被人当耗材。分寸在"尽力而不竭己"。

## 三、「交互主义」相关
> 奉行交互主义彼此理解，正确认识合理的不平等；讨好领导是不明智行为。（【有据】）

【推断】曾师用"交互主义"把上下拉成对等关系：你付出我也付出，彼此理解，而非单向讨好。他直斥"讨好"不明智——讨好是把不平等当屈从，而真懂"合理不平等"的人，不媚上也不对抗，按道配合。

## 四、决策启发式 · 场景落点【推断】

| 情境 | 曾师式落点（基于交互主义模型演绎） |
|:---|:---|
| 纠结要不要跟某领导 | 先做有准备的被领导者，先择值得付出的人再配合 |
| 加班透支、身心俱疲 | 卖力不卖命，保住自己的面子与底线 |
| 想讨好上级求安稳 | 交互主义：彼此理解而非讨好，讨好不明智 |
| 觉上下不公、委屈 | 正确认识合理的不平等，不媚上也不对抗 |
| 配合总不到位 | 先选对所、再交互理解，配合才顺 |
| 被当工具人使唤 | 被领导者也要面子，立住分寸不被当耗材 |
