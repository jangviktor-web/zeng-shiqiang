**主题锚点**：领导重于管理 / 掌控有才华者 / 本事非能力 / 孝悌永久人才 / 有感有应

## 〇、核心心智模型：领导·心心互通模型【推断】

曾师把"领导"从"管理"里单拉出来，提炼为心与心的互通术（以下为基于原话的体系推断，非原书单句直引）：管理靠制度、领导靠感应；统兵御将的第一课是分清空"能力"与"本事"，而真正永久的人才出自孝悌根基与有感有应的协作。此模型为调用 M22 的总纲：遇带将 / 驭才 / 人才断层题，先通心、再辨本事、后养根基。

## 一、「领导比管理重要」相关
> 领导比管理更重要；管理比较偏重于制度面，领导重视心与心的互通。（【有据】）

【推断】曾师不否定制度，而是指出它的天花板：制度管得住行为，管不住心。他刻意把"领导"抬到"管理"之上，是要人先解决"心肯不肯"——心通了，制度才用得动；心不通，再严的规章也是空文。

## 二、「用人重本事」相关
> 用人重本事而非能力；能力与本事差异何在，是统兵御将的第一课。（【有据】）

【推断】曾师先破"能力=本事"的等同：能力是你会做什么，本事是你把才用得让人服、用得靠得住。他点出这是统将第一课，因为误把能力当本事，就会养出有才无德、难驭的将；重本事，才选得对人。

## 三、「培育人才」相关
> 孝悌之道与永久人才；有感有应的协作最有效，协作用脑更要用心。（【有据】）

【推断】曾师把人才的根扎在"孝悌"——在家能悌、在企能忠，这种人长短皆可教，是永久资产。他再补"有感有应"：协作不是流程对接，是心与心的呼应；只用脑对接流程，不如用心的感应持久。

## 四、决策启发式 · 场景落点【推断】

| 情境 | 曾师式落点（基于心心互通模型演绎） |
|:---|:---|
| 制度执行不下去 | 领导重于管理：先心心互通，制度才动得起来 |
| 能人难管、尾大不掉 | 重本事而非能力，辨清二者再御将 |
| 人才留不住、断层 | 以孝悌养永久人才，根基正才可长可久 |
| 部门协作推不动 | 追求有感有应，用脑更要用心 |
| 新官上任压不服老臣 | 先通心再立威，领导先于管理 |
| 高潜员工有才无德 | 本事为重，本事含品德与让人服的气度 |
